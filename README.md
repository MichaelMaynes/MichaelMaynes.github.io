# Michael Maynes Portfolio Website

Personal portfolio website for Michael G. Maynes Jr., an IT Technician and Cybersecurity and Network Systems student at Eastern Florida State College.

Website: https://michaelmaynes.github.io

## Files

- `index.html` — website content and structure
- `style.css` — website styling
- `Michael_Maynes_Resume.pdf` — public resume without a phone number

## Publishing on GitHub Pages

Upload these files to the root of the `MichaelMaynes.github.io` repository. Replace the older versions of `index.html`, `style.css`, and `Michael_Maynes_Resume.pdf` with these updated files.
